# Rios Business Intelligence Dashboard

## 📊 Overview
This repository contains a complete analytical case built in Power BI for the Rios company.  
The dashboard includes dynamic filtering, DAX measures, and four analytical modules:

- Sales  
- Logistics  
- Payments  
- Feedback  

The final dashboard is published as a **PDF report**.  
The PBIX file is intentionally not included.

## 🧩 Key Features

### 🔹 Dynamic Filters
- Date (Year, Quarter, Month)  
- Product  
- Customer / Seller  
- Category groups  

### 🔹 DAX Measures
All measures used in the project are documented in:

👉 `/docs/DAX_Measures.md`

### 🔹 Analytical Modules
- **Sales:** revenue, average check, top products, funnel  
- **Logistics:** delivery performance, freight cost, cycle time  
- **Payments:** payment types, installment logic, totals  
- **Feedback:** review scores, comments, response time
